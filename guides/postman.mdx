## Installation

<Steps>
  <Step title="Importez la collection">
    Dans Postman : **Import → File**, sélectionnez le fichier téléchargé.
  </Step>
  <Step title="Créez un environnement">
    **Environments → Create**, avec les variables suivantes :

    | Variable | Valeur |
    |---|---|
    | `API_KEY` | Votre clé `DJN-…` |
    | `API_SECRET` | Votre secret API |
    | `MERCHANT_REFERENCE` | Votre référence marchand |
    | `TOKEN` | Le `access_token` renvoyé par `login-merchant` |
  </Step>
  <Step title="Sélectionnez l'environnement et testez">
    Commencez par **merchant → get balance** pour vérifier vos identifiants, puis **transactions → initiate a payment** pour créer un lien.
  </Step>
</Steps>
