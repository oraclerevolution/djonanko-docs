<Tip>
La charge complète (`payload`) est incluse : vous pouvez la traiter directement, sans attendre un rejeu.

Surveillez cet endpoint : une accumulation de `FAILED` ou `ABANDONED` signifie que vous perdez des confirmations d'encaissement.
</Tip>
