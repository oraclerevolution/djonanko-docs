---
title: "Renouveler votre secret de signature"
openapi: "POST /merchants/me/webhook-secret/rotate"
---

<Warning>
**Coupure immédiate.** Les notifications sont signées avec le nouveau secret dès cet appel ; l'ancien n'est plus accepté. Déployez-le sans délai, sinon toutes vos vérifications de signature échoueront.

Si vous ne pouvez pas déployer instantanément, faites accepter les deux secrets par votre code pendant la fenêtre de bascule.
</Warning>
