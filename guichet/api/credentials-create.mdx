<Warning>
Le secret n'est affiché qu'une seule fois.

Pour une rotation sans coupure : émettez, déployez, vérifiez `lastUsedAt`, **puis** révoquez l'ancienne. Plusieurs paires peuvent être actives simultanément.
</Warning>
